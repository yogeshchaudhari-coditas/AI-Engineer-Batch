# Customer Support Email Routing System


Features:

Email Reading: Reads customer emails from the emails/ directory.

Customer Details Extraction: Extracts the customer's name and email address.

Order ID Extraction: Identifies order IDs from email content using regular expressions.

Order Lookup: Checks whether the referenced order exists in the company's order data.

Email Categorization: Defines categories for refund requests, order status, product complaints, account/login issues, and other queries.

Priority Assignment: Supports high, medium, and low priority levels.

Email Forwarding Preview: Prints a formatted email preview for the appropriate support team in the terminal.

CSV-Based Order Data: Uses a local CSV file to store sample order information.
